# RFCs

Public APIs, file formats and architecture will need an accepted RFC before implementation.

1. Copy `0000-template.md` to the next free four-digit number and a short title. Never reuse a number.
2. Open a pull request with status `Draft`.
3. When the author says it is ready, a maintainer will start a 7-day `Final comment period`.
4. A maintainer will record `Accepted` or `Rejected` and the reason at the top, then merge it. Rejected proposals will be kept.

See the [org-wide process](https://github.com/GIKSN-RESEARCH/.github/blob/main/CONTRIBUTING.md#rfcs).
